# Telegram VPN Bot

Телеграм-бот для оформления и продления подписки на VPN сервис с реферальной системой.

## Возможности

- ✅ Оформление и продление подписки
- ✅ Выбор тарифного плана (месяц, 3 месяца, 6 месяцев, год)
- ✅ Управление количеством устройств (+5% за каждое дополнительное)
- ✅ Реферальная система с промокодами
- ✅ Автоматический расчет скидок
- ✅ Генерация конфигурационных файлов для устройств
- ✅ Управление устройствами через бота

## Установка

1. Клонируйте репозиторий или скачайте файлы

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Получите токен бота у [@BotFather](https://t.me/BotFather) и добавьте его в `.env`:
```
BOT_TOKEN=your_bot_token_here
INITIAL_ADMIN_ID=your_telegram_user_id

# Настройки Xray
XRAY_CONFIG_PATH=/usr/local/etc/xray/config.json
XRAY_BIN_PATH=/usr/local/bin/xray
XRAY_SERVER_ADDRESS=your-server.com
XRAY_PROTOCOL=vless
XRAY_PORT_VLESS=443
XRAY_PORT_VMESS=8443
XRAY_PORT_TROJAN=8444
XRAY_PORT_SS=8445
```

Где:
- `INITIAL_ADMIN_ID` - ваш Telegram ID (можно получить у бота @userinfobot). Это добавит вас как первого администратора при запуске бота.
- `XRAY_CONFIG_PATH` - путь к конфигурационному файлу Xray Core
- `XRAY_BIN_PATH` - путь к исполняемому файлу Xray
- `XRAY_SERVER_ADDRESS` - доменное имя или IP адрес вашего VPN сервера
- `XRAY_PROTOCOL` - используемый протокол: `vless`, `vmess`, `trojan` или `ss`
- `XRAY_PORT_*` - порты для соответствующих протоколов

## Запуск

```bash
python bot.py
```

## Настройка администраторов

После первого запуска добавьте администратора командой:
```
/addadmin <user_id>
```

Где `<user_id>` - это ваш Telegram ID (можно получить у бота @userinfobot).

**Важно:** Первого администратора можно добавить через переменную окружения `INITIAL_ADMIN_ID` в файле `.env`. Это автоматически добавит вас как администратора при первом запуске бота.

После этого вы можете добавлять других администраторов командой `/addadmin <user_id>`.

## Тарифы

- Месяц - 120₽
- 3 месяца - 300₽
- 6 месяцев - 550₽
- Год - 1000₽

Каждое дополнительное устройство (после первого) добавляет +5% к стоимости.

## Реферальная система

- Каждый пользователь получает уникальный промокод после первой подписки
- При использовании промокода друга: пользователь получает 10% скидку
- Владелец промокода получает скидку:
  - 1 реферал: 15% скидка
  - 2 реферала: 30% скидка
  - 3 реферала: 45% скидка
  - И так далее до 100% скидки
- Скидка применяется только если все рефералы имеют активную подписку

## База данных

Используется SQLite. База данных создается автоматически при первом запуске.

Таблицы:
- `users` - пользователи и их промокоды
- `subscriptions` - подписки пользователей
- `devices` - устройства пользователей
- `referrals` - реферальные связи

## Особенности

- Все кнопки находятся под сообщением (inline кнопки)
- Везде присутствует кнопка "Назад" для возврата в главное меню
- Продление подписки требует одобрения администратора
- После нажатия "Я оплатил" заявка отправляется всем администраторам
- Администраторы могут одобрить или отклонить заявку через кнопки
- **Автоматическая генерация конфигураций Xray** для всех протоколов
- **Автоматическое добавление/удаление пользователей** в Xray Core
- **Отправка конфигураций** через Telegram в виде ссылок для импорта

## Настройка Xray Core

Бот автоматически управляет конфигурацией Xray Core:

1. **Генерация конфигураций**: При запросе устройства автоматически создается пользователь в Xray и генерируется ссылка для импорта
2. **Добавление пользователей**: Новые устройства автоматически добавляются в конфиг Xray и вызывается перезагрузка сервиса
3. **Удаление пользователей**: При удалении устройства пользователь автоматически удаляется из Xray
4. **Поддерживаемые протоколы**: VLESS, VMESS, Trojan, Shadowsocks

**Требования:**
- Xray Core установлен и настроен на сервере
- Бот имеет доступ к файлу конфигурации Xray
- Права на перезагрузку Xray (через systemctl)
- Права sudo для перезагрузки сервиса

## Примечания

- Платежная система не интегрирована (требуется добавление)
- Автоматическое продление подписки пока не реализовано
- Уведомления о скором окончании подписки требуют cron/scheduler
